Syllabus Coverage — WBSCTE CST/4/404 Object-Oriented Programming

1. Virtual Functions & VTable

When a class declares a virtual function, the compiler inserts a hidden pointer vptr inside every object. At runtime, calls via base pointer resolve through the class's vtable, achieving dynamic polymorphism.

2. Four Pillars of OOP

Encapsulation: Bundling data with methods & data hiding.
Abstraction: Exposing essential interface via abstract classes/pure virtual functions.
Inheritance: Reusability & hierarchical classification.
Polymorphism: Compile-time (overloading) & Run-time (virtual functions).

3. Memory Management: new & delete

Objects created with new are allocated in Heap Memory. Virtual destructors (virtual ~Base()) ensure derived destructors execute first, preventing memory leaks.

4. Exception Handling

Robust error recovery using try, catch, and throw blocks to separate error detection from error handling routines.
