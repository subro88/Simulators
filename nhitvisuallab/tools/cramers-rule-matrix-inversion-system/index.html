📖 Theoretical Foundations: Cramer's Rule & Matrix Inversion

1. Cramer's Theorem Proof via Determinant Multilinearity

Let $A = [\vec{a}_1, \vec{a}_2, \dots, \vec{a}_n]$ be an $n \times n$ matrix. The linear system $A\vec{x} = \vec{b}$ expands as the linear combination: $$x_1 \vec{a}_1 + x_2 \vec{a}_2 + \dots + x_n \vec{a}_n = \vec{b}$$ Substitute $\vec{b}$ into the $i$-th column of $A$ to form matrix $A_i$: $$\det(A_i) = \det([\vec{a}_1, \dots, \sum_{k=1}^n x_k \vec{a}_k, \dots, \vec{a}_n])$$ By the multilinearity of determinants across column vectors: $$\det(A_i) = \sum_{k=1}^n x_k \det([\vec{a}_1, \dots, \vec{a}_k, \dots, \vec{a}_n])$$ Whenever $k \ne i$, the determinant contains two identical columns $(\vec{a}_k \text{ and } \vec{a}_k)$, which identically vanishes to zero. The only remaining non-zero term occurs when $k = i$: $$\det(A_i) = x_i \det([\vec{a}_1, \dots, \vec{a}_i, \dots, \vec{a}_n]) = x_i \det(A)$$ Dividing by $\det(A) \ne 0$ yields Cramer's explicit identity: $$x_i = \frac{\det(A_i)}{\det(A)}$$

2. Matrix Inversion via Adjugate Formulation

The fundamental identity linking an invertible matrix $A$ to its adjugate is: $$A \cdot \text{adj}(A) = \det(A) \cdot I_n$$ where $[\text{adj}(A)]_{ij} = C_{ji} = (-1)^{i+j} M_{ji}$. If $\det(A) \ne 0$, dividing both sides by $\det(A)$ proves: $$A^{-1} = \frac{1}{\det(A)} \text{adj}(A)$$ Multiplying $A^{-1}$ by $\vec{b}$: $$\vec{x} = A^{-1} \vec{b} = \frac{1}{\det(A)} (\text{adj}(A) \cdot \vec{b})$$ The $i$-th row of $\text{adj}(A) \cdot \vec{b}$ evaluates to $\sum_{j=1}^n C_{ji} b_j$, which is precisely the Laplace expansion of the column-substituted matrix determinant $\det(A_i)$. Thus, Cramer's Rule and Matrix Inversion are algebraically identical!

📖 Comprehensive User Guide & Experimental SOP Manual

1. Principle & Theoretical Overview

Cramer’s rule provides an explicit formula for the solution of a system of linear equations with as many equations as unknowns, valid whenever the system has a unique solution ($D = \det(A) \ne 0$). The simulation verifies this relationship both algebraically and geometrically in $\mathbb{R}^2$ and $\mathbb{R}^3$.

2. Step-by-Step Laboratory Procedure
  1. Select system dimension ($2 \times 2$ or $3 \times 3$).
  2. Input the coefficient matrix $A$ and constant vector $\vec{b}$ manually or load the curated benchmark presets.
  3. Inspect the Master Determinant card: verify the Laplace expansion along row 1.
  4. Observe the modified column determinants $D_x, D_y, D_z$ where column $i$ is replaced with $\vec{b}$.
  5. Verify Cramer’s quotient: $x_i = D_i / D$.
  6. Switch to the Matrix Inversion tab: follow the minors matrix, check sign flips for cofactors, transpose for the adjugate, and multiply $A^{-1}\vec{b}$.
  7. Explore the 3D Spatial Studio: rotate the camera around the intersecting planes and column parallelepiped.
  8. Log the completed trial to the Observation Notebook and export the final lab report as a CSV.
3. Geometric Interpretations (Row vs. Column Picture)

Row Picture: Each equation $a_{i1}x + a_{i2}y + a_{i3}z = b_i$ represents a flat plane in $\mathbb{R}^3$. The solution is the point intersection of all three planes.

Column Picture: The equation $x_1 \vec{a}_1 + x_2 \vec{a}_2 + x_3 \vec{a}_3 = \vec{b}$ represents reaching vector $\vec{b}$ by scaling column basis vectors. The volume of the parallelepiped spanned by $\vec{a}_i$ equals $|\det(A)|$.

4. Diagnostic Singularity & Inconsistency Identification

When $\det(A) = 0$, Cramer's rule cannot divide by zero. Inspect the modified determinants: - If any $D_i \ne 0$, the planes do not intersect at any common point (e.g. triangular prism or parallel sheets) $\implies$ Inconsistent system. - If all $D_i = 0$, the planes intersect along a continuous line or are coincident $\implies$ Dependent system with infinitely many solutions.

5. Numerical Benchmark Problem

Benchmark 3x3 Problem: Row 1: $1x + 2y + 3z = 9$ | Row 2: $2x - 1y + 1z = 8$ | Row 3: $3x + 0y - 1z = 3$. $D = 20, D_x = 40 \implies x = 2.00$; $D_y = -20 \implies y = -1.00$; $D_z = 60 \implies z = 3.00$.
