Syllabus Coverage — WBSCTE CST/3/305 Computer Organization & Architecture

1. Instruction Cycle (Von Neumann Architecture)

Divided into 3 major phases: Fetch ($PC \to MAR \to MDR \to IR$, $PC \gets PC + 1$), Decode (Control Unit generates control signals), and Execute (ALU operation and register writeback).

2. Cache Memory Mapping

Direct Mapping: $\text{Block} = \text{Address} \pmod{\text{Cache Lines}}$. Fast but subject to conflict misses.
Set-Associative: Divides cache into sets of $k$ lines (2-way, 4-way), reducing conflict misses significantly.

3. Booth's Multiplication Algorithm

Optimized signed 2's complement integer multiplication by encoding sequences of consecutive 1s. Inspects bits $(Q_0, Q_{-1})$: $10 \to A = A - M$, $01 \to A = A + M$, followed by Arithmetic Right Shift (ARS).

4. 5-Stage Instruction Pipelining

Overlaps instruction execution through IF (Instruction Fetch), ID (Instruction Decode / Register Read), EX (Execute / ALU), MEM (Memory Access), and WB (Write Back). Ideal speedup equals the number of stages $k = 5$.
