Syllabus Coverage — WBSCTE CST/3/305: Computer Organization & Architecture

🖉 1. 16-bit RISC Instruction Formats

The machine implements a fixed-length 16-bit RISC architecture with three uniform instruction formats:

R-Type (Register Format): [Opcode: 4b | Rd: 3b | Rs1: 3b | Rs2: 3b | Funct: 3b]. Arithmetic and bitwise operations: ADD, SUB, AND, OR, XOR, SLT, SLL, SRL.

I-Type (Immediate/Load-Store): [Opcode: 4b | Rd: 3b | Rs1: 3b | Imm: 6b]. Memory loads/stores and conditional branches: ADDI, LW, SW, BEQ.

J-Type (Jump Format): [Opcode: 4b | Target: 12b]. Direct address branches: JMP, JAL.

🚀 2. 5-Stage RISC Pipelining Dynamics

Execution decomposes into 5 independent clock phases separated by pipeline registers (IF/ID, ID/EX, EX/MEM, MEM/WB):

• IF (Fetch): $MAR \leftarrow PC; PC \leftarrow PC + 1; MDR \leftarrow MEM[MAR]; IR \leftarrow MDR$
• ID (Decode): Register read $A \leftarrow Reg[Rs1], B \leftarrow Reg[Rs2]$; Sign extension.
• EX (Execute): ALU computation and branch target address calculation.
• MEM (Memory): Memory read (LW) or write (SW) access.
• WB (Writeback): Destination register update $Reg[Rd] \leftarrow ALU_{out}$ or $MDR$.

Ideal Speedup: $S_k = \frac{k \cdot n}{k + n - 1} \xrightarrow{n \to \infty} k = 5\times$

⚠ 3. Pipeline Hazards & Forwarding Logic

RAW (Read-After-Write) Data Hazards: Resolved via the hardware Forwarding Unit. When an instruction in EX requires a register being written by EX/MEM or MEM/WB, multiplexers bypass the result directly to the ALU inputs (ForwardA / ForwardB = 10&sub2; or 01&sub2;).

Load-Use Data Hazard: When an instruction immediately follows a LW that produces its operand. Cannot forward backward in time; hardware must insert 1 stall bubble (NOP) and freeze PC + IF/ID.

Control Hazards (Branches): Branch resolution takes 1 cycle (in ID) or 2 cycles (in EX). Mispredictions trigger a pipeline flush.

💾 4. Hierarchical Cache Memory & AMAT

Exploits spatial and temporal locality. Addresses break down into:

Address = [ Tag : $M - s - b$ bits | Set Index : $s$ bits | Block Offset : $b$ bits ]

Direct-Mapped: 1 block per set. Fast, simple, but susceptible to conflict misses.
Set-Associative: $K$ blocks per set with LRU replacement to reduce conflict misses.
AMAT Equation: $\text{AMAT} = t_{\text{hit}} + (\text{Miss Rate} \times t_{\text{miss-penalty}})$.

📖 Laboratory Student Manual & Operations Guide

1. Step Execution: Click Step Clock to step through instruction cycles. Observe instructions transit through IF, ID, EX, MEM, and WB bays.

2. Load-Use Hazards: Run Preset 1. Notice how LW R3, 0(R0) followed by ADD R4, R3, R2 injects a hatched amber NOP bubble into EX, freezing PC and IF/ID for one clock cycle.

3. Forwarding Unit Bypass: Toggle Forwarding Unit from Enabled to Disabled. Notice how raw data dependencies require multiple software/hardware stalls when forwarding is turned off.

4. Cache Thrashing Experiment: Select Preset 4 and switch to Cache Memory Lab. Watch how alternating memory access to addresses that map to the same set index creates continuous conflict misses in a Direct-Mapped cache, and how switching to 2-Way Set-Associative eliminates thrashing.
