Single-Phase Full-Wave SCR Bridge Lab — Theory & Governing Equations

Single-phase fully controlled four-thyristor bridges regulate DC output power smoothly by controlling the thyristor gate firing delay angle $\alpha$. With continuous inductive load current, the average DC output voltage is $V_{dc} = \frac{2 V_m}{\pi} \cos\alpha$. Operating in the range $0^\circ \le \alpha < 90^\circ$ produces rectification, while $90^\circ < \alpha < 180^\circ$ enables synchronous line-commutated DC-to-AC inversion.
