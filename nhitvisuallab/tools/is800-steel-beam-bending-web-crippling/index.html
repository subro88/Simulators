IS 800 Steel Beam & Web Crippling Lab — Theory & Governing Equations

Laterally supported steel beams reach their full plastic flexural moment ($M_d = \frac{\beta_b Z_p f_y}{\gamma_{m0}}$) without lateral-torsional buckling. Concentrated reactions at supports are checked for web bearing crippling ($P_{wc} = \frac{(b_1 + n_2) t_w f_{yw}}{\gamma_{m0}}$) and web shear buckling per IS 800 Clause 8.2.

📖 User Guide & Operating Manual

1. Overview

Laterally supported steel beams reach their full plastic flexural moment ($M_d = \frac{\beta_b Z_p f_y}{\gamma_{m0}}$) without lateral-torsional buckling. Concentrated reactions at supports are checked for web bearing crippling ($P_{wc} = \frac{(b_1 + n_2) t_w f_{yw}}{\gamma_{m0}}$) and web shear buckling per IS 800 Clause 8.2.

2. Setting Up the Load Case & Parameters

Adjust the sliders and input fields on the left. Click Calculate & Analyze to run the solvers.

3. Building the Diagrams & Diagnostic Telemetry

The interactive canvas dynamically visualizes bolted plate layouts, column buckling curves, web crippling dispersion lines, seismic story force pyramids, gravity dam thrust vectors, flow net grids, and FRP confinement rings based on live analytical equations.

4. Reading the Theory

Switch to the Explore & Theory tab to review formal WBSCTE curriculum formulas, derivations, and state equations.

5. Try a Problem

Verify laboratory workshop measurements against simulator predictions to test understanding.

6. Design Notes & Standards

All calculations conform to standard Indian Standard codes (IS 800:2007, IS 1893:2016, IS 13920:2016, IS 6512, IS 13311, ACI 440.2R).
