Dumpy & Auto Level Levelling Lab — Theory & Governing Equations

Differential levelling determines elevation differences between topographic bench marks and ground points. The Height of Instrument (HI) method establishes an optical collimation reference line ($HI = BM + BS; RL = HI - FS/IS$). Reduction is cross-checked using the Rise & Fall identity ($\sum BS - \sum FS = \sum Rise - \sum Fall = Last\_RL - First\_RL$).

The Height of Instrument (HI) method establishes an optical collimation reference line ($HI = BM + BS; RL = HI - FS/IS$). Reduction is cross-checked using the Rise & Fall identity ($\sum BS - \sum FS = \sum Rise - \sum Fall = Last\_RL - First\_RL$).
