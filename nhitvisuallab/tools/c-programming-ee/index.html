#include <stdio.h>
int main() {
    float R11 = 7.0, R12 = -2.0, R22 = 12.0;
    float V1 = 20.0, V2 = -10.0;
    float det = (R11 * R22) - (R12 * R12);
    float I1 = (V1 * R22 - V2 * R12) / det;
    float I2 = (R11 * V2 - R12 * V1) / det;
    printf("Mesh I1 = %.3f A, I2 = %.3f A\n", I1, I2);
    return 0;
}

Syllabus Coverage — WBSCTE EE/S3/C Programming Concept using C

1. 2D Arrays for Matrix Algebra

Solving simultaneous linear network equations $[R][I] = [V]$ using Cramer's Rule determinants and Gauss Elimination loops.

2. Numerical Integration in C

Calculating RMS voltage $V_{rms} = \sqrt{\frac{1}{T}\int_0^T v^2(t)dt}$ and active power using Trapezoidal and Simpson's algorithms in C functions.

3. Pointers & Memory Allocation

Dynamic arrays (malloc, free) for real-time oscilloscope buffer sampling and signal telemetry processing.

4. File Handling (stdio.h)

Exporting electrical load curve datasets to CSV files (fopen, fprintf) for power system reporting.
