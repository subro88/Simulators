Intel 8085 Microprocessor Architecture & Theory

1. Register Array & Flag Status Register

The 8085 incorporates six general-purpose 8-bit registers (B, C, D, E, H, L) which can be combined into 16-bit register pairs: BC, DE, HL. The HL pair serves as the primary data memory pointer M.

Flag Register (F) Layout:

$$\begin{array}{|c|c|c|c|c|c|c|c|} \hline \mathbf{D_7} & \mathbf{D_6} & \mathbf{D_5} & \mathbf{D_4} & \mathbf{D_3} & \mathbf{D_2} & \mathbf{D_1} & \mathbf{D_0} \\ \hline \mathbf{S} & \mathbf{Z} & 0 & \mathbf{AC} & 0 & \mathbf{P} & 1 & \mathbf{CY} \\ \hline \end{array}$$

  • Sign Flag (S): Set if $D_7 = 1$ (negative result in 2's complement).
  • Zero Flag (Z): Set if ALU result is identically zero ($00\text{H}$).
  • Auxiliary Carry (AC): Set if carry occurs from bit $D_3$ to $D_4$ (used by DAA).
  • Parity Flag (P): Set if total number of 1-bits is even (Even Parity).
  • Carry Flag (CY): Set if unsigned addition overflows bit $D_7$, or borrow occurs in subtraction.

2. Demultiplexing the Address/Data Bus (74LS373)

To reduce chip pin count to 40, the 8085 multiplexes the lower 8 bits of address with data on pins AD0–AD7.

  • T1 State: 8085 places higher address on A8–A15 and lower address on AD0–AD7. It pulses ALE (Address Latch Enable) HIGH.
  • 74LS373 Latch: On the falling edge of ALE, an external octal latch (74LS373) captures and holds A0–A7 for the rest of the machine cycle.
  • T2–T3 States: AD0–AD7 is released to carry bidirectional 8-bit data, activated by $\overline{\text{RD}}$ or $\overline{\text{WR}}$.

3. Machine Cycles & T-State Waveforms

Every instruction execution consists of 1 to 5 Machine Cycles ($M_1$ through $M_5$), each composed of 3 to 6 T-states (clock periods):

  • Opcode Fetch (OF, 4T or 6T): $M_1$ cycle where instruction opcode is fetched from memory. Status: $IO/\overline{M}=0, S_1=1, S_0=1$.
  • Memory Read (MR, 3T): Reads data byte from RAM. Status: $IO/\overline{M}=0, S_1=1, S_0=0$.
  • Memory Write (MW, 3T): Writes data byte to RAM. Status: $IO/\overline{M}=0, S_1=0, S_0=1$.
  • I/O Read (IOR, 3T) & I/O Write (IOW, 3T): Interfacing with input/output peripheral ports. Status: $IO/\overline{M}=1$.

4. Addressing Modes & Interrupt Hierarchy

  • Immediate: Operand specified directly in instruction (e.g., MVI A, 32H, LXI H, 2050H).
  • Direct: 16-bit memory address specified directly (e.g., LDA 2050H, STA 2060H).
  • Register: Data transferred between registers (e.g., MOV A, B, ADD C).
  • Register Indirect: Memory addressed through HL, BC, or DE (e.g., MOV A, M, STAX B).
  • Implicit / Implied: Operand implied by opcode (e.g., CMA, RAL, HLT).

Interrupt Priority & Vectors:

1. TRAP (Non-maskable, $0024\text{H}$) > 2. RST 7.5 ($003C\text{H}$) > 3. RST 6.5 ($0034\text{H}$) > 4. RST 5.5 ($002C\text{H}$) > 5. INTR ($0038\text{H}$).
