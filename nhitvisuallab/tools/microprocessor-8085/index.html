Syllabus Coverage — WBSCTE CST/4/401 Microprocessor & Programming

1. 8085 CPU Register Structure

8-bit Accumulator (A) for ALU operations, 6 general-purpose 8-bit registers (B, C, D, E, H, L) combinable as 16-bit register pairs (BC, DE, HL). 16-bit Program Counter (PC) and Stack Pointer (SP).

2. Flag Status Register

5 active hardware flip-flops: Sign (S) bit 7, Zero (Z) bit 6, Auxiliary Carry (AC) bit 4 (BCD arithmetic), Parity (P) bit 2 (even parity), and Carry (CY) bit 0.

3. Instruction Machine Cycles & Timing

Divided into Opcode Fetch (4/6 T-States), Memory Read (3 T-States), Memory Write (3 T-States), I/O Read/Write, and Interrupt Acknowledge.

4. Interrupt Architecture

Hardware interrupts with priority order: TRAP (Non-Maskable, RST 4.5) > RST 7.5 > RST 6.5 > RST 5.5 > INTR.
