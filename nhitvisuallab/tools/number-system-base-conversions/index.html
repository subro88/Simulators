📖 Theoretical Foundations: Positional Radix Mathematics

1. Positional Radix Value Theorem

In any positional number system of base $b$, the total numerical quantity represented by a sequence of digits is given by the weighted polynomial expansion: $$N_b = \sum_{i=0}^{n-1} d_i \cdot b^i + \sum_{j=1}^{m} f_{-j} \cdot b^{-j}$$ where $0 \le d_i, f_j < b$. When converting to base 10, evaluating this polynomial summation yields the exact decimal equivalent.

2. Division-by-R Algorithm Proof

By the Euclidean Division Algorithm, any integer $N$ can be uniquely expressed as $N = q_0 \cdot b + r_0$, where $0 \le r_0 < b$. Here, $r_0$ is precisely the least significant digit (LSD). Repeating the process on the quotient $q_0 = q_1 \cdot b + r_1$ recursively yields the next digits: $$N = ((\dots(q_k \cdot b + r_k)\dots) \cdot b + r_1) \cdot b + r_0$$ Reading remainders in reverse order (bottom-to-top) reconstructs the exact radix-$b$ positional representation.

3. Signed Two's Complement Ring Arithmetic

In an $n$-bit register, Two's Complement defines negative values modulo $2^n$: $$-X \equiv 2^n - X \pmod{2^n} = (\sim X) + 1$$ This representation allows addition and subtraction to be performed with the exact same binary adder hardware without requiring separate sign handling logic, eliminating the problematic dual zero ($+0$ and $-0$) inherent to One's Complement.

1. Principle & Theoretical Overview

Digital computing architectures operate exclusively in discrete base representations (primarily binary, octal, and hexadecimal). This virtual lab enables students to visualize the mechanical algorithms used to convert numbers between any arbitrary radices $b \in [2, 36]$.

3. Power-of-Two Fast Grouping Shortcut

Because $8 = 2^3$ and $16 = 2^4$, conversions between Binary, Octal, and Hexadecimal do not require converting to Base 10. Simply partition bits into groups of 3 (for Octal) or groups of 4 (for Hex) starting from the radix point, and map each group directly to its corresponding character.

4. Two's Complement Inversion Rules

To negate an integer in Two's Complement: 1. Invert every bit ($0 \to 1$ and $1 \to 0$). 2. Add $1$ to the least significant bit. Notice that the most significant bit (MSB) acts as the sign indicator ($1 = \text{negative}, 0 = \text{positive}$).

Engineering Reference & Laboratory Standards: Digital Number Base Systems

Digital computational hardware relies fundamentally on binary logic levels (0 and 1). To represent data concisely, computer scientists utilize higher power-of-two radices such as octal (base 8) and hexadecimal (base 16).

Positional Notation & Radix Conversion Algorithms

In repeated division by radix $b$, the remainder obtained at each successive step corresponds to increasing powers of the base ($b^0, b^1, \dots$). Consequently, the remainder sequence must be read in reverse order from bottom to top (MSD to LSD). In repeated fractional multiplication, the integer parts are extracted downwards ($f_{-1}, f_{-2}, \dots$).

Two's Complement Binary Arithmetic

Two's complement simplifies hardware architecture by allowing subtraction to be performed with standard binary addition circuits ($A - B = A + (\sim B + 1)$). The system possesses a unique representation for zero and provides clean modular ring properties.
