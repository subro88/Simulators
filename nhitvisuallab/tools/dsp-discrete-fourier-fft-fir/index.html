📖 User Guide & Operating Manual

1. Overview

The Discrete Fourier Transform (DFT) converts discrete-time sequences into frequency domain spectra. The Radix-2 Cooley-Tukey Fast Fourier Transform (FFT) reduces computational complexity from $\mathcal{O}(N^2)$ to $\mathcal{O}(N\log_2 N)$. Finite Impulse Response (FIR) digital filters designed via windowing ($h[n] = h_d[n] w[n]$) guarantee linear phase and absolute stability.
