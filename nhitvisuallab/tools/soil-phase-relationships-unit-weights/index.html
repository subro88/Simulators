Soil Phase Relationships & Unit Weights Lab — Theory & Governing Equations

Soil is a three-phase particulate system comprising mineral solids, pore water, and pore air. Fundamental phase relationships quantify the soil state: Void Ratio ($e = V_v / V_s$), Porosity ($n = V_v / V$), Degree of Saturation ($S_r = V_w / V_v$), and Dry Unit Weight ($\gamma_d = \frac{\gamma}{1+w} = \frac{G_s \gamma_w}{1+e}$).

📖 User Guide & Operating Manual

1. Overview

Soil is a three-phase particulate system comprising mineral solids, pore water, and pore air. Fundamental phase relationships quantify the soil state: Void Ratio ($e = V_v / V_s$), Porosity ($n = V_v / V$), Degree of Saturation ($S_r = V_w / V_v$), and Dry Unit Weight ($\gamma_d = \frac{\gamma}{1+w} = \frac{G_s \gamma_w}{1+e}$).

2. Setting Up the Load Case & Parameters

Use the control sliders on the left to configure survey angles, soil phase values, pavement loads, or canal discharges. Click Calculate & Analyze to run the solvers.

3. Building the Diagrams & Diagnostic Telemetry

The interactive canvas dynamically plots real-time survey vectors, 3-phase soil diagrams, retaining wall pressures, or canal sections corresponding to the exact state equations.

4. Reading the Theory

Switch to the Explore & Theory tab to review formal WBSCTE curriculum formulas, derivations, and state equations.

5. Try a Problem

Verify laboratory workshop measurements against simulator predictions to test understanding.

6. Design Notes & Standards

All calculations conform to standard Indian Standard codes (IRC:73, IRC:37, IS 2720, IS 73, IS 1205, IS 1208, IS 2386).
