Challenge 1: Implement 2-Input XOR with NAND Gates

Target: Construct a 2-Input Exclusive-OR (XOR) gate using EXACTLY 4 two-input NAND gates and no other gate types.

Boolean Derivation:
A ⊕ B = A•B' + A'•B = (A•(A•B)')' • (B•(A•B)')'.
NAND 1 calculates (A•B)'. NAND 2 computes (A•(A•B)')'. NAND 3 computes (B•(A•B)')'. NAND 4 combines their outputs, yielding exactly A ⊕ B in 4 gates.

Syllabus Coverage — WBSCTE CST/3/303: Digital Logic Design

🖉 1. Combinational Logic & Universal Gates

NAND and NOR gates are Universal Gates capable of constructing all elementary operations (AND, OR, NOT) without ancillary components:

• NOT: $A \text{ NAND } A = \bar{A}$
• AND: $(A \text{ NAND } B) \text{ NAND } (A \text{ NAND } B) = A \cdot B$
• OR: $(\bar{A}) \text{ NAND } (\bar{B}) = A + B$ (De Morgan's Theorem).

De Morgan's Laws: $\overline{A \cdot B} = \bar{A} + \bar{B}, \quad \overline{A + B} = \bar{A} \cdot \bar{B}$

🧮 2. Adders & Arithmetic MSI Blocks

Half Adder: Computes sum of two single-bit inputs: $\text{Sum} = A \oplus B$, $\text{Carry} = A \cdot B$.

Full Adder: Accommodates incoming carry bit $C_{\text{in}}$:

$\text{Sum} = A \oplus B \oplus C_{\text{in}}, \quad C_{\text{out}} = A \cdot B + C_{\text{in}} \cdot (A \oplus B)$

📊 3. Karnaugh Map (K-Map) Minimization

K-Maps represent Boolean functions graphically using Gray-code ordering ($00, 01, 11, 10$) where adjacent cells differ by exactly 1 bit:

• Group sizes must be powers of two: $1, 2, 4, 8, 16$.
• Toroidal edge-wrapping allows corners and opposite sides to group.
• "Don't Cares" ($X$) can be treated as $1$ to form larger groups or $0$ if not beneficial.

⚡ 4. Sequential Logic & Flip-Flops

Sequential circuits feature feedback memory governed by clock signals:

• JK Flip-Flop: Eliminates indeterminate state of SR latch. When $J=1, K=1$, toggles output: $Q_{n+1} = \bar{Q}_n$.
• Setup & Hold Times: Data input must remain stable for time $t_s$ before clock edge and $t_h$ after edge to avert metastability ($X$).
