Syllabus Coverage — WBSCTE CST/3/303 Digital Logic Design Lab

1. Combinational Arithmetic Circuits

Half Adder: Computes sum of two single-bit inputs. $S = A \oplus B$, $C = A \cdot B$.
Full Adder: Adds three 1-bit binary inputs including previous carry: $S = A \oplus B \oplus C_{in}$, $C_{out} = AB + BC_{in} + AC_{in}$.

2. Data Routing: Multiplexers (MUX)

Selects binary information from one of $2^n$ input data lines and directs it to a single output line based on $n$ select lines. Widely used for parallel-to-serial conversion and boolean function implementation.

3. Sequential Circuits: Flip-Flops

JK Flip-Flop: Eliminates the invalid state of the SR flip-flop. Characteristic equation: $Q_{next} = J\overline{Q} + \overline{K}Q$. When $J=K=1$, the output toggles on every clock edge.

4. Binary Counters & Shift Registers

Asynchronous (Ripple) and Synchronous counters built using cascaded T or JK flip-flops. A 4-bit counter counts through 16 states ($0000_2$ to $1111_2$, MOD-16).
