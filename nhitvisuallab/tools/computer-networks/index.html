Computer Networks Theoretical Formulations & Architectures

1. IPv4 Bitwise Mathematics, CIDR & VLSM

An IPv4 address is an unsigned 32-bit integer $A \in [0, 2^{32}-1]$. Given prefix length $p \in [0, 32]$:

$$\text{Subnet Mask } M = 2^{32} - 2^{32 - p}, \qquad \text{Wildcard Mask } W = \sim M = 2^{32 - p} - 1$$

$$\text{Network ID } N = A \ \& \ M, \qquad \text{Broadcast IP } B = N \ \vert \ W$$

$$\text{Usable Host Capacity} = 2^{32 - p} - 2 \quad (p \le 30)$$

Variable Length Subnet Masking (VLSM): Departments sorted by host requirements $H_1 \ge H_2 \ge \dots \ge H_k$. For each subnet, minimum host bits $h_i = \lceil \log_2(H_i + 2) \rceil \implies p_i = 32 - h_i$.

2. OSI 7-Layer vs TCP/IP Protocol Data Units

Data descends the transmitter stack via encapsulation and ascends the receiver stack via decapsulation:

  • Layer 7–5 Application: Payload Data (HTTP GET, DNS query, ICMP echo).
  • Layer 4 Transport: Adds TCP header ($20\text{ B}$) or UDP header ($8\text{ B}$). Ports route to specific processes; TCP adds sequence/ACK numbers and flags (SYN, ACK, FIN).
  • Layer 3 Network: Adds IPv4 header ($20\text{ B}$). Carries 32-bit Source/Destination IP and TTL (Time-To-Live, decremented at every router hop).
  • Layer 2 Data Link: Adds Ethernet II header ($14\text{ B}$) with 48-bit MAC addresses and Frame Check Sequence trailer ($4\text{ B}$ CRC-32).
  • Layer 1 Physical: Converts bitstreams into Manchester / NRZ-I electrical signals on copper/fiber.

3. Dynamic Routing: Bellman-Ford (RIP) vs Dijkstra SPF (OSPF)

Distance-Vector (RIPv2): Each router $x$ updates distance vector $D_x(y)$ to destination $y$ via neighbor $v$ based on the Bellman-Ford equation:

$$D_x(y) = \min_{v} \left\{ c(x, v) + D_v(y) \right\}$$

Metric is hop count (maximum 15 hops; 16 = infinity / unreachable). Uses Split Horizon with Poison Reverse to prevent routing loops.

Link-State (OSPFv2): Routers flood Link-State Advertisements (LSAs) and run Dijkstra's Shortest Path First (SPF) algorithm:

$$\text{Cost} = \max\left(1, \left\lfloor \frac{100\text{ Mbps}}{\text{Link Bandwidth}} \right\rfloor\right)$$

4. Layer-2 Switching & Address Resolution Protocol (ARP)

  • CAM Table Learning: When a frame enters port $P$, switch inspects Source MAC and records $\{ \text{Src MAC}, P, \text{timer} \}$.
  • Forwarding: If Destination MAC is in CAM table, switch forwards exclusively to that port (Known Unicast). If missing, it floods the frame out all other ports (Unknown Unicast Flooding).
  • ARP Operation: To resolve IP to MAC, sender broadcasts an ARP Request (`Who has 192.168.1.1? Tell 192.168.1.10`). Target unicasts an ARP Reply, populating sender's ARP cache.
