Syllabus Coverage — WBSCTE CST/4/402 Computer Networks

1. OSI 7-Layer Reference Model

Layer 7: Application (HTTP, DNS) • Layer 6: Presentation (SSL/TLS) • Layer 5: Session • Layer 4: Transport (TCP/UDP) • Layer 3: Network (IP, ICMP) • Layer 2: Data Link (Ethernet MAC) • Layer 1: Physical (Bits/Cables).

2. Classless Inter-Domain Routing (CIDR)

Replaced rigid Class A, B, C allocations with flexible prefix lengths. Total assignable host addresses on subnet equals $2^{(32 - \text{prefix})} - 2$ (excluding network and broadcast addresses).

3. Dijkstra Shortest Path Routing

Used by Open Shortest Path First (OSPF) Link-State protocol. Maintains network graph topology and iteratively selects unvisited node with lowest cumulative distance from source.

4. Sliding Window Flow Control

Go-Back-N: Sender window $N$, receiver window 1. Retransmits all frames from damaged frame onward.
Selective Repeat: Individual frame ACK and selective retransmission.
