Syllabus Coverage — WBSCTE CST/4/405 Computer Graphics

1. Bresenham's Integer Line Algorithm

Eliminates floating-point arithmetic and rounding errors in DDA by using integer decision parameter $P_k = 2\Delta y - \Delta x$. Fast and hardware-efficient for GPU scanline conversion.

2. Midpoint Circle Algorithm

Exploits 8-way circle symmetry. Decision parameter at midpoint $M$: $P_k = 1 - r$. If $P_k < 0$, select pixel $E$ ($P_{k+1} = P_k + 2x_{k+1} + 1$), else select $SE$ ($P_{k+1} = P_k + 2x_{k+1} + 1 - 2y_{k+1}$).

3. 2D Geometric Transformations

Represented via $3 \times 3$ homogeneous matrices: Translation ($T$), Scaling ($S$), and Rotation ($R$). Allows composite transformations via matrix multiplication ($M = M_3 \cdot M_2 \cdot M_1$).

4. Cohen-Sutherland Line Clipping

Assigns 4-bit region outcodes (Top, Bottom, Right, Left: TBRL) to endpoints. Trivial Accept if $\text{Code}_1 \lor \text{Code}_2 = 0000_2$, Trivial Reject if $\text{Code}_1 \land \text{Code}_2 \neq 0000_2$.
