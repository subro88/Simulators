Syllabus Coverage — WBSCTE EE/S5/MPMC Microprocessor & Microcontroller

1. 8051 Timers & Serial Communication

Timer 1 in Mode 2 (8-bit auto-reload) acts as UART baud rate generator. $\text{Baud} = \frac{2^{\text{SMOD}}}{32} \times \frac{f_{osc}}{12 \times (256 - \text{TH1})}$. Using $11.0592\text{MHz}$ crystal allows exact zero-error standard baud rates ($9600, 4800, 2400$).

2. Stepper Motor Interfacing

4-Phase unipolar stepper motor driven via ULN2003 Darlington array connected to Port P1. Step sequences: Full-step 4-phase ($1000 \to 0100 \to 0010 \to 0001$) and Half-step 8-phase.

3. Interrupt Architecture

5 vectored interrupts: External INT0 ($0003\text{H}$), Timer 0 ($000B\text{H}$), External INT1 ($0013\text{H}$), Timer 1 ($001B\text{H}$), and Serial RI/TI ($0023\text{H}$).

4. Memory Organization

Separate Program (ROM) and Data (RAM) address spaces (Harvard architecture). 128 bytes internal RAM (Bank 0-3, Bit-addressable area $20\text{H}-2\text{FH}$, General RAM) and Special Function Registers (SFRs).
