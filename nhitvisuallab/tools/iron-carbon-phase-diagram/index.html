Syllabus Coverage — WBSCTE ME/S3/MEM Iron-Carbon Equilibrium Phase Diagram Lab

1. Three Invariant Reactions in Fe-C

Peritectic (1495°C): $\text{Liquid } (0.53\%C) + \delta (0.09\%C) \rightleftharpoons \gamma (0.17\%C)$
Eutectic (1147°C): $\text{Liquid } (4.3\%C) \rightleftharpoons \gamma (2.11\%C) + \text{Fe}_3\text{C} (6.67\%C)$ [Ledeburite]
Eutectoid (727°C): $\gamma (0.77\%C) \rightleftharpoons \alpha (0.022\%C) + \text{Fe}_3\text{C} (6.67\%C)$ [Pearlite]

2. The Lever Rule for Phase Fractions

For an alloy of composition $C_0$ in a two-phase region $(\alpha + \beta)$ with tie line endpoints $C_\alpha$ and $C_\beta$: $W_\alpha = \frac{C_\beta - C_0}{C_\beta - C_\alpha}$ and $W_\beta = \frac{C_0 - C_\alpha}{C_\beta - C_\alpha}$.

3. Microstructural Constituents

Ferrite (α): Soft, ductile BCC interstitial solid solution ($\le 0.022\%C$).
Austenite (γ): Ductile FCC solid solution ($\le 2.11\%C$).
Cementite (Fe3C): Extremely hard, brittle intermetallic compound ($6.67\%C$).
