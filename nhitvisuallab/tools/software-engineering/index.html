Syllabus Coverage — WBSCTE CST/5/501 Software Engineering

1. COCOMO Estimation Models

Constructive Cost Model proposed by Barry Boehm. Computes Effort ($E = a \cdot \text{KLOC}^b$) and Schedule Duration ($D = c \cdot E^d$) across Organic, Semi-Detached, and Embedded project categories.

2. McCabe Cyclomatic Complexity

Measures structural complexity of code via Control Flow Graphs (CFG): $V(G) = E - N + 2P$ (or $V(G) = P + 1$ where $P$ is the number of predicate decision nodes). Defines the number of independent test cases required for complete branch coverage.

3. Agile Scrum Methodology

Iterative development with Product Backlog, Sprint Planning, Daily Standup, Sprint Review, and Retrospective. Team velocity measured in Story Points per 2-to-4 week timebox.

4. Black-Box & White-Box Testing

Black-Box: Equivalence Class Partitioning (ECP) & Boundary Value Analysis (BVA).
White-Box: Statement Coverage, Branch/Decision Coverage, Condition Coverage, and Basis Path Testing.
