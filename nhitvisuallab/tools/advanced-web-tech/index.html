Syllabus Coverage — WBSCTE CST/6/603(II) Advanced Web Technology

1. JSON Web Tokens (JWT)

Stateless authentication standard (RFC 7519) consisting of 3 Base64Url parts separated by dots: Header.Payload.Signature. Eliminates server-side session memory storage in distributed microservices.

2. WebSocket Protocol (RFC 6455)

Full-duplex, bidirectional communication over a single TCP socket connection. Initiated via HTTP 101 Switching Protocols handshake, minimizing packet overhead vs HTTP polling.

3. Cross-Origin Resource Sharing (CORS)

Security mechanism using HTTP headers (Access-Control-Allow-Origin, Preflight OPTIONS) to permit or block cross-origin AJAX requests in modern web browsers.

4. Single Page Applications (SPA)

Client-side routing (HTML5 History API pushState) with decoupled REST/GraphQL API backends and component state management.
