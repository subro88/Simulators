Syllabus Coverage — WBSCTE EE/S3/BE Basic Electronics

1. Zener Diode as Voltage Regulator

Operates in reverse breakdown avalanche region with near-vertical $I-V$ characteristic. Maintains constant $V_z$ despite supply voltage ($V_{in}$) or load resistance ($R_L$) fluctuations as long as $I_z \ge I_{z,min}$.

2. BJT Common Emitter (CE) Amplifier

Provides both voltage and current gain with a $180^\circ$ phase reversal. Voltage gain $A_v = -g_m (R_C \parallel R_L)$ and stability governed by emitter resistor $R_E$ negative feedback.

3. Full-Wave Bridge Rectifier & Filters

Converts AC to DC using 4 bridge diodes. PIV $= V_m$. Shunt capacitor filter smooths pulsating DC ripple: $\gamma = \frac{1}{4\sqrt{3} f C R_L}$.

4. Field Effect Transistors (JFET & MOSFET)

Voltage-controlled unipolar devices with extremely high input impedance ($10^9 \Omega$). Shockley equation: $I_D = I_{DSS} \left(1 - \frac{V_{GS}}{V_P}\right)^2$.
