Syllabus Coverage — WBSCTE CST/4/403 Relational Database Management System

1. Relational Database Normalization

1NF: Atomic values (no multi-valued attributes).
2NF: 1NF + No partial dependency (non-prime attributes fully dependent on candidate key).
3NF: 2NF + No transitive dependency ($X \to Y \to Z$).
BCNF: For every functional dependency $X \to Y$, $X$ must be a superkey.

2. ACID Transaction Properties

Atomicity: All-or-nothing execution via undo logs.
Consistency: Preserves database integrity constraints.
Isolation: Concurrency control avoiding dirty reads.
Durability: Committed updates persist after power failure.

3. Relational Algebra Operations

Selection ($\sigma$), Projection ($\pi$), Cartesian Product ($\times$), Set Union ($\cup$), Set Difference ($-$), Natural Join ($\bowtie$), and Theta Join.

4. B+ Tree Indexing

Self-balancing multi-way search tree where all data pointers reside in leaf nodes, linked sequentially for efficient range queries ($O(\log_B N)$ search complexity).
