Syllabus Coverage — WBSCTE CST/5/502 Java Programming

1. JVM Architecture & Memory Areas

Divided into Method Area (class metadata), Heap Area (objects & instance variables), JVM Stack (stack frames & local variables), PC Registers, and Native Method Stacks.

2. Multithreading & Synchronization

Created via extends Thread or implements Runnable. synchronized keyword ensures mutual exclusion on object monitors to prevent race conditions and dirty reads.

3. Garbage Collection (GC)

Automatic memory management using Mark-and-Sweep algorithms divided into Young Generation (Eden & Survivor spaces for short-lived objects) and Tenured / Old Generation.

4. Java Collections Framework

ArrayList (dynamic resizing array), LinkedList (doubly-linked list), HashMap (hash table with $O(1)$ average lookup), and TreeSet (Red-Black self-balancing BST).
