📖 User Guide & Operating Manual

1. Overview

Shapers, slotters, and planers utilize the classic Crank and Slotted Lever Quick Return Motion Mechanism (QRMM) to minimize idle time on the non-cutting return stroke. This simulator computes the cutting stroke angle, return stroke angle, cutting velocity profile, single-point tool forces, and machining cycle time.

2. Setting Up the Load Case & Parameters

Use the control sliders on the left to configure operating variables. Click Calculate & Simulate to trigger real-time Python/JS physics solvers.

3. Building the Diagrams & Diagnostic Telemetry

The interactive canvas dynamically plots real-time thermodynamic, kinematic, or metrology curves corresponding to the exact mathematical state.

4. Reading the Theory

Switch to the Explore & Theory tab to review formal WBSCTE curriculum formulas, derivations, and state equations.

5. Try a Problem

Verify laboratory workshop measurements against simulator predictions to test understanding.

6. Design Notes & Standards

All calculations conform to standard mechanical engineering practices (ASME, ISO, IS 1991, IS 5359, IS 2984).
