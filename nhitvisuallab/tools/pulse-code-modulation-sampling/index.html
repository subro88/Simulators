Pulse Code Modulation (PCM) & Sampling Lab — Theory & Governing Equations

Pulse Code Modulation (PCM) is the digital standard for telephony and optical transmission. Continuous bandlimited signals are sampled at or above the Nyquist rate ($f_s \ge 2 f_m$), quantized into $2^n$ discrete levels with step size $\Delta$, and transmitted as binary bitstreams at bitrate $R_b = n f_s$ with $SQNR = 6.02 n + 1.76\text{ dB}$.
