1. JDBC Architecture & PreparedStatements

4 JDBC Driver Types (Type-4 Pure Java Thin driver). PreparedStatement compiles SQL queries with positional placeholders (?), preventing SQL Injection attacks and boosting query execution speed.

2. Servlet Lifecycle & Filters

Servlet container invokes init() on first load, multithreaded service() dispatching to doGet()/doPost(), and destroy() on shutdown.

3. Session Management

State persistence across HTTP requests using: (1) Cookies, (2) HttpSession API with JSESSIONID, (3) URL Rewriting (encodeURL), and (4) Hidden Form Fields.

4. MVC Architecture & JSP / JSTL

Model (JavaBeans/Entities), View (JSP with JSTL tags & Expression Language ${...}), and Controller (Servlets handling request routing and business logic delegation).
