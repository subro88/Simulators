Syllabus Coverage — WBSCTE CST/5/505(I) Network Management & Administration

1. DNS Recursive vs Iterative Queries

Hierarchical distributed naming system. Resolves Fully Qualified Domain Names (FQDN) via Root Servers (.), Top-Level Domain (TLD) servers (.in, .com), and Authoritative Zone servers with resource records (A, AAAA, CNAME, MX).

2. DHCP 4-Way DORA Handshake

Discover: Broadcast search for available DHCP servers.
Offer: Server unicasts IP offer with lease parameters.
Request: Client formally requests lease of selected IP.
Acknowledge: Server commits lease binding to client MAC.

3. Simple Network Management Protocol (SNMP)

Architecture: Manager, Agent, and MIB (Management Information Base) tree. Commands: GET, SET, GET-NEXT, and asynchronous event notifications (TRAP / INFORM).

4. Network Firewalls & ACLs

Stateless packet filtering vs Stateful inspection. Evaluates 5-tuple: Source IP, Dest IP, Source Port, Dest Port, and Protocol (TCP/UDP) against sequential Access Control List (ACL) permit/deny rules.
