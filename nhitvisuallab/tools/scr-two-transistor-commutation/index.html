SCR Two-Transistor Model & Commutation Lab — Theory & Governing Equations

Silicon Controlled Rectifiers (SCRs) model as interconnected PNP ($T_1$) and NPN ($T_2$) transistor pairs. When gate trigger current drives the loop gain sum $\alpha_1 + \alpha_2 \to 1$, regenerative feedback latches the device into low-resistance conduction ($I_A = \frac{\alpha_2 I_g + I_{CO}}{1 - (\alpha_1+\alpha_2)}$). RC snubbers prevent inadvertent $dv/dt$ false triggering.

📖 User Guide & Operating Manual

1. Overview

Silicon Controlled Rectifiers (SCRs) model as interconnected PNP ($T_1$) and NPN ($T_2$) transistor pairs. When gate trigger current drives the loop gain sum $\alpha_1 + \alpha_2 \to 1$, regenerative feedback latches the device into low-resistance conduction ($I_A = \frac{\alpha_2 I_g + I_{CO}}{1 - (\alpha_1+\alpha_2)}$). RC snubbers prevent inadvertent $dv/dt$ false triggering.
