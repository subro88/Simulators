Syllabus Coverage — WBSCTE CST/3/304 Data Structures

1. Stack Data Structure (LIFO)

A linear data structure following the Last In, First Out principle. Used in recursion, expression evaluation (Infix to Postfix conversion), and undo operations. Fundamental operations are push(), pop(), and peek() with $O(1)$ constant time complexity.

2. Queue Data Structure (FIFO)

Follows First In, First Out order. Enqueue operates at the Rear pointer and Dequeue operates at the Front pointer. Used in CPU job scheduling, printer spooling, and Breadth-First Search (BFS).

3. Dynamic Linked List

Nodes stored non-contiguously in heap memory with data and pointer fields. Enables dynamic memory allocation without fixed size constraints. Insertion/deletion at head is $O(1)$, linear search is $O(n)$.

4. Binary Search Tree (BST)

Hierarchical tree structure where each node satisfies: $\text{Left Child} < \text{Root} < \text{Right Child}$. In-order traversal yields ascending sorted keys. Search and insertion are $O(\log n)$ average.
