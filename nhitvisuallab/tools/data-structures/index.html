Syllabus Theory & Mathematical Invariants — WBSCTE CST/3/304

📋 1. Dynamic Array Amortized Resizing

When an array reaches logical size $N = C$ (capacity), a new block of physical capacity $2C$ is allocated. All $N$ items are copied over.

$$\Phi(D_i) = 2 \cdot \text{size} - \text{capacity}$$ $$\hat{c}_i = c_i + \Phi(D_i) - \Phi(D_{i-1}) = 1 + 2 = 3 = O(1)$$

By aggregate potential method, inserting $N$ items takes $\le 3N$ elementary writes, establishing $O(1)$ amortized insertion.

🔗 2. Linked List Pointer Mechanics

Singly Linked Lists maintain $\text{Node} = \{\text{key}, \text{next}\}$. Prepending requires $O(1)$ by updating the Head reference:

$$\text{newNode.next} = \text{head}; \quad \text{head} = \text{newNode}$$

Doubly Linked Lists maintain dual sockets ($\text{prev}, \text{next}$), enabling $O(1)$ arbitrary node deletion when a direct node pointer is held.

🌳 3. Binary Search Tree (BST) & AVL Balance Factor

For every node $u$, $\forall v \in \text{LeftSubtree}(u), \text{key}(v) < \text{key}(u)$ and $\forall w \in \text{RightSubtree}(u), \text{key}(w) > \text{key}(u)$.

$$BF(u) = \text{height}(\text{LeftSubtree}) - \text{height}(\text{RightSubtree}) \in \{-1, 0, +1\}$$

When $|BF(u)| \ge 2$, single (LL, RR) or double (LR, RL) rotations restore equilibrium in $O(1)$ pointer operations.

⚖ 4. Binary Heap Complete Tree Invariant

A complete binary tree mapped contiguously into an array $A[0 \dots n-1]$. For index $i$:

$$\text{Parent}(i) = \lfloor (i - 1)/2 \rfloor, \quad \text{Left}(i) = 2i + 1, \quad \text{Right}(i) = 2i + 2$$

Max-Heap Property: $A[\text{Parent}(i)] \ge A[i]$. Sift-Up and Sift-Down preserve the invariant in $O(\log n)$ height swaps.

⚡ 5. QuickSort Lomuto Partition Invariant

Given pivot element $P = A[\text{high}]$, pointer $i$ demarcates elements $\le P$ while $j$ sweeps unfamiliar elements:

$$\forall k \in [\text{low}, i]: A[k] \le P \quad \wedge \quad \forall k \in [i+1, j-1]: A[k] > P$$

Average running time satisfies $T(n) = 2T(n/2) + \Theta(n) \implies O(n \log n)$.

🖇 6. Graph Search & Shortest Paths

Breadth-First Search (BFS): Discovers vertices in increasing order of shortest-path distance using a FIFO queue in $O(V + E)$.

$$\text{Dijkstra Relaxation: } \text{if } d[u] + w(u, v) < d[v] \implies d[v] = d[u] + w(u, v)$$

Implemented with a min-priority queue achieving $O((V + E) \log V)$ time complexity.

5 Comprehensive Questions on Memory Representation, Traversal Invariants, and Asymptotics

Score: 0 / 5
1. In Lomuto's QuickSort partitioning scheme, what invariant is preserved for all elements in index range $[\text{low} \dots i]$?
A. All elements are strictly greater than the pivot element.
B. All elements are less than or equal to the pivot element ($A[k] \le P$).
C. Elements are sorted in ascending order.
D. Elements are equal to the median of the array.
Correct! Pointer $i$ maintains the boundary where everything from $\text{low}$ to $i$ is confirmed $\le \text{pivot}$.
2. Why does doubling capacity ($C \to 2C$) in dynamic arrays achieve $O(1)$ amortized insertion rather than $O(N)$?
A. Memory reallocation is handled by hardware registers in $O(1)$.
B. It only copies odd-indexed elements.
C. Reallocations become geometrically infrequent, distributing copy cost across many cheap inserts.
D. Virtual memory pointers do not need physical copying.
Correct! The geometric progression $\sum_{k=0}^{\log N} N/2^k < 2N$ proves the total copy cost is bounded linearly by $2N$.
3. An in-order depth-first traversal of a valid Binary Search Tree (BST) produces:
A. The keys in strictly non-decreasing (sorted) order.
B. The keys ordered from root to deepest leaf.
C. A reverse post-order topological order.
D. A complete heap array representation.
Correct! Because In-Order visits $\text{LeftSubtree} \to \text{Root} \to \text{RightSubtree}$, it naturally emits sorted keys.
4. In an array-backed binary Max-Heap of size $N$, the left child and parent of an element at index $i$ are:
A. $\text{Left} = 2i, \quad \text{Parent} = i/2$
B. $\text{Left} = 2i + 1, \quad \text{Parent} = \lfloor(i - 1)/2\rfloor$
C. $\text{Left} = i + 1, \quad \text{Parent} = i - 1$
D. $\text{Left} = 2i + 2, \quad \text{Parent} = 2i$
Correct! 0-indexed complete binary trees use $2i+1$ for left child and $\lfloor(i-1)/2\rfloor$ for parent.
5. What is the time complexity of Dijkstra's algorithm implemented with a min-heap priority queue for a graph $G = (V, E)$?
A. $O(V^2)$
B. $O((V + E) \log V)$
C. $O(V \cdot E)$
D. $O(V!)$
Correct! Each vertex is extracted once ($V \log V$) and each edge relaxation updates the heap ($E \log V$), totaling $O((V+E)\log V)$.
