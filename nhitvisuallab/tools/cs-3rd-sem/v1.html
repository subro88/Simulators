📖 User Guide — CS & Technology 3rd Semester Lab
1 Overview

This virtual lab reproduces the core hands-on exercises from the WBSCTE Computer Science & Technology 3rd-semester syllabus. It pairs a set of interactive data-structure simulations with an inline 3D model of the lab setup. Use the Simulate tab to practise each topic, the 3D Model tab to inspect the apparatus, and Explore to review the syllabus mapping.

Topics covered: Set Theory, Stack (LIFO), Queue & Circular Queue (FIFO), Singly Linked List, Binary Search Tree (insert/search/delete/traversals), Sorting visualizer (Bubble, Insertion, Quick, Merge) and Graph traversal (BFS / DFS).

2 Using the Simulate Mode

When you open the page you are in Simulate mode with the lab panel visible. Pick a topic from the row of tabs (Set Theory, Stack, Queue, Linked List, BST, Sorting, Graph). Each module has its own input fields, buttons and a live result area.

For example, in Stack type a value and click Push to add it to the top; Pop removes the top element. In Queue toggle between Linear and Circular to see how the tail wraps to the head. In Sorting choose an algorithm and press Play or Step to watch comparisons and swaps animate.

3 The 3D Model

Switch to the 3D Model tab to open an interactive 3D view. Drag to rotate, scroll to zoom and right-drag to pan. The right-hand carousel lists the modelled components — select one to focus the camera on it. Use the fullscreen button (top-right of the 3D panel) for a larger view.

4 Syllabus Mapping

The Explore tab lists the full 3rd-semester coverage so you can confirm which lab exercise maps to which syllabus point: Discrete Mathematics (Set Theory, Relations & Functions, Matrix Theory, Counting Techniques, Graph Theory, Trees) and the Data Structure Using C lab (Stack, Queue & Circular Queue, Linked Lists, Recursion/Fibonacci, Sorting, Binary Tree & BST, Graph BFS/DFS).

Computer Science & Technology — 3rd Semester Virtual Laboratory

The Computer Science & Technology 3rd-semester coursework introduces two foundational pillars: Discrete Mathematics and Data Structures using C. This virtual lab lets diploma and polytechnic students practise both without needing a physical computer lab. Set-theory operations (union, intersection, difference, complement) build the logical foundation for relational databases and automata, while the data-structure modules (stack, queue, linked list, BST, sorting and graph traversal) develop the algorithmic thinking required for higher semesters.

Why Practise Data Structures Interactively?

A stack is a Last-In-First-Out structure used in function-call management and expression evaluation. A queue is First-In-First-Out; its circular variant is essential in buffering and real-time systems. Linked lists teach dynamic memory and pointer manipulation, and binary search trees demonstrate efficient search, insertion and deletion with ordered traversals (in-order, pre-order, post-order). Sorting and graph traversal (BFS/DFS) are among the most frequently tested and interview-relevant topics in the syllabus.

Topics Covered

  • Set Theory — universal set, union, intersection, difference, complement.
  • Stack — push/pop, overflow/underflow, LIFO behaviour.
  • Queue & Circular Queue — enqueue/dequeue, linear vs circular wrapping.
  • Linked List — insert at end, delete by value, traversal.
  • Binary Search Tree — insert, search, delete, ordered traversals.
  • Sorting — Bubble, Insertion, Quick, Merge with step/play animation.
  • Graph Traversal — BFS and DFS ordering from a fixed example graph.
