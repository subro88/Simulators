Syllabus Coverage — WBSCTE CST/6/602 System Programming & Compiler Design

1. Six Phases of a Compiler

1. Lexical Analysis (Tokens) • 2. Syntax Analysis (Parse Tree) • 3. Semantic Analysis (Type Checking) • 4. Intermediate Code Generation (TAC) • 5. Code Optimization (Peephole) • 6. Target Code Generation (Assembly).

2. Top-Down vs Bottom-Up Parsers

Top-Down: Recursive Descent & LL(1) using First and Follow sets.
Bottom-Up: Shift-Reduce, LR(0), SLR(1), and LALR(1) parsing using item deterministic finite automata.

3. Intermediate Representations

Three-Address Code (TAC), Postfix notation, Syntax Trees, and Data Structure representations (Quadruples: [op, arg1, arg2, res], Triples, and Indirect Triples).

4. Code Optimization Techniques

Compile-time evaluation (Constant Folding), Common Subexpression Elimination, Dead Code Elimination, and Loop-Invariant Code Motion.
