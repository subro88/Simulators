Syllabus Coverage — WBSCTE CST/6/PP-IV Cloud Computing & Cyber Security

1. RSA Public-Key Cryptography

Asymmetric cipher based on integer factorization hardness. Key generation: $n = pq$, $\phi(n) = (p-1)(q-1)$, $ed \equiv 1 \pmod{\phi(n)}$. Encryption $C = M^e \pmod n$, Decryption $M = C^d \pmod n$.

2. Cryptographic Hash Functions (SHA-256)

One-way Merkle-Damgård compression producing fixed 256-bit digests. Properties: Pre-image resistance, 2nd pre-image resistance, and strict Avalanche effect collision resistance.

3. Cloud Service Models

IaaS: AWS EC2, raw VMs and networking.
PaaS: Google App Engine, runtime environments.
SaaS: End-user software applications (Google Workspace, Office 365).

4. Container Virtualization & Docker

OS-level lightweight virtualization sharing the host OS kernel via Linux Namespaces (PID, NET, MNT) and Control Groups (cgroups), avoiding hypervisor VM overhead.
