Syllabus Coverage — WBSCTE CST/5/505(II) Multimedia & Animation

1. Cubic Bezier Curves

Parametric curve governed by 4 control points: $B(t) = (1-t)^3 P_0 + 3(1-t)^2 t P_1 + 3(1-t)t^2 P_2 + t^3 P_3$ where $0 \le t \le 1$. Essential for smooth physics-based animation easing.

2. JPEG DCT Image Compression

Converts spatial pixel blocks to frequency domain via 2D Discrete Cosine Transform: $F(u, v) = \frac{1}{4} C(u) C(v) \sum_{x=0}^7 \sum_{y=0}^7 f(x, y) \cos\left[\frac{(2x+1)u\pi}{16}\right]\cos\left[\frac{(2y+1)v\pi}{16}\right]$, followed by quantization table scaling.

3. Huffman Lossless Coding

Variable-length prefix coding assigning shorter binary codewords to frequently occurring symbols, achieving optimal entropy compression.

4. Color Models

Additive RGB (Displays), Subtractive CMYK (Printing), and Perceptual HSL/HSV & YCbCr (Luma + Chroma subsampling 4:4:4, 4:2:2, 4:2:0).
