Syllabus Coverage — WBSCTE EE/S6/IA Industrial Automation & PLC

1. IEC 61131-3 Programming Languages

Ladder Diagram (LD), Function Block Diagram (FBD), Structured Text (ST), Instruction List (IL), and Sequential Function Chart (SFC).

2. Timer & Counter Instructions

TON (Timer On-Delay): Starts timing when input is true; sets Done bit when $ET \ge PT$.
TOF (Timer Off-Delay) & CTU/CTD (Up/Down Pulse Counters).

3. PLC Hardware & Scan Cycle

Three cyclic phases: 1. Input Scan (Image table update), 2. Program Execution (Rung logic evaluation), 3. Output Update (Field actuator switching). Typical scan time $1-5\text{ms}$.

4. SCADA & Industrial Networks

Human-Machine Interface (HMI) screens, Alarming, Trend logging, Modbus RTU/TCP, Profinet, and OPC UA integration.
