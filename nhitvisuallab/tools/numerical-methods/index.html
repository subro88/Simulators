Syllabus Coverage — WBSCTE CST/6/603(I) Numerical Methods

1. Newton-Raphson Method

Root finding using tangent line Taylor approximation: $x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$. Exhibits quadratic convergence ($p=2$) near simple roots.

2. Simpson's 1/3 & 3/8 Rules

Approximates integrand with piecewise 2nd-order parabolas: $\int_a^b f(x)dx \approx \frac{h}{3}[f(x_0) + 4f(x_1) + f(x_2)]$. Error term is $O(h^4)$, exact for polynomials up to degree 3.

3. Gauss-Seidel Iterative Method

Solves strictly diagonally dominant linear systems $Ax = b$ iteratively using updated component values immediately in the current iteration step.

4. Lagrange & Newton Interpolation

Constructs unique polynomial of degree $\le n$ passing through $n+1$ discrete data points $(x_i, y_i)$ via divided differences.
