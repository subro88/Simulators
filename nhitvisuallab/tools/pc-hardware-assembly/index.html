1. Motherboard Form Factors & Architecture

ATX (305 × 244 mm): Standard desktop board with up to 7 expansion slots.
Micro-ATX (244 × 244 mm): Compact board with 4 slots.
Components include: VRM MOSFETs, Chipset (PCH), LGA/PGA CPU socket, DIMM slots, and M.2 PCIe Gen 4/5 slots.

2. Dual-Channel Memory Interleaving

Installing RAM modules in matched pairs (Slots A2 & B2) doubles the memory bus width from 64-bit to 128-bit, effectively doubling aggregate theoretical memory bandwidth ($\text{Bandwidth} = \frac{\text{Clock} \times 8 \times 2}{1000}\text{ GB/s}$).

3. SMPS Power Supply Sizing

Calculate peak TDP of CPU + GPU + 80W base peripheral load. Apply an industry standard 1.25× to 1.35× continuous multiplier for peak transient spikes and 80 PLUS efficiency curves.

4. BIOS / UEFI POST Diagnostics

Power-On Self-Test (POST) validates CPU registers, DMA controllers, system timer, DRAM, and video controller. Audible beep codes and diagnostic 7-segment Q-codes pinpoint failing hardware prior to video initialization.
