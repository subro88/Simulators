Syllabus Coverage — WBSCTE CST/5/503 Operating Systems

1. Process Scheduling Algorithms

FCFS: Non-preemptive, suffers from Convoy Effect.
SJF/SRTF: Provably optimal minimum average waiting time.
Round Robin: Preemptive time-sliced sharing ($q$), balances responsiveness.

2. Banker's Deadlock Avoidance

Maintains Available vector, Max matrix, and Allocation matrix. Safely tests whether granting a resource request leaves the system in a state where all processes can finish ($\text{Need} \le \text{Work}$).

3. Virtual Memory & Paging

Non-contiguous memory allocation dividing logical memory into Pages and physical memory into Frames. Page Replacement algorithms: FIFO (Belady's Anomaly), LRU (Stack-based), and Optimal.

4. Disk Arm Scheduling

SSTF (Shortest Seek Time First), SCAN (Elevator algorithm), and C-SCAN (Circular SCAN) optimizing magnetic disk head travel distance.
