Syllabus Coverage — WBSCTE CST/6/603(III) Digital Image Processing

1. Spatial Domain Filtering

Neighborhood convolution operation $g(x, y) = \sum_{s=-a}^a \sum_{t=-b}^b w(s, t) f(x+s, y+t)$. Smoothing filters reduce noise (Gaussian, Mean, Median), while derivative filters sharpen edges.

2. Sobel & Prewitt Edge Detection

Calculates 1st order partial derivatives along $x$ and $y$ axis: $G_x = \frac{\partial f}{\partial x}, G_y = \frac{\partial f}{\partial y}$. Gradient magnitude $G = \sqrt{G_x^2 + G_y^2}$ and direction $\theta = \arctan(G_y / G_x)$.

3. Histogram Equalization

Global contrast enhancement transformation: $s_k = T(r_k) = (L-1) \sum_{j=0}^k p_r(r_j)$ where $p_r(r_j)$ is the normalized probability density of gray level $r_j$.

4. Morphological Image Processing

Set theory operations on binary/grayscale shapes using Structuring Elements: Dilation $A \oplus B$, Erosion $A \ominus B$, Opening $(A \ominus B) \oplus B$, and Closing $(A \oplus B) \ominus B$.
