Rectifier circuits convert alternating current (AC) to direct current (DC) using semiconductor PN junction diodes. A capacitor smoothing filter lowers output ripple according to $r = \frac{1}{4\sqrt{3} f C R_L}$, while clipping and clamping diode circuits reshape signal wave peaks and DC reference levels.
